# 🎮 网页小游戏合集

> 23 款纯前端小游戏，零依赖、单文件、即开即玩。

## 快速开始

直接双击对应的 `.html` 文件即可在浏览器中运行，无需安装任何依赖。

## 🛠️ 技术特点

- **零依赖**：所有游戏为单个 HTML 文件，无需安装任何框架或库
- **即开即玩**：双击 HTML 文件即可在浏览器中运行
- **Web Audio API**：音效和背景音乐全部通过 Web Audio API 合成，无需外部音频文件
- **Canvas 2D**：大部分游戏使用 Canvas 进行高性能渲染
- **响应式设计**：适配桌面和移动端触控操作
- **本地存储**：最高分等数据通过 `localStorage` 持久保存
